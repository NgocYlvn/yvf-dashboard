# YVF Performance Dashboard

A ready-to-run Streamlit dashboard styled for Yusen Logistics.

## Run
Double-click `RUN_DASHBOARD.bat` on Windows.

## Data structure
The default Excel file is located at `data/YVF_PowerBI_Ready.xlsx` and should contain:

- `Data_Booking`
- `Data_SI`
- `Data_Issue`
- `Customer_Feedback`

## Update data
Upload a new `.xlsx` file from the sidebar, or replace the default file while keeping the same sheet and column names.

## Stop
Press `Ctrl + C` in the command window.
