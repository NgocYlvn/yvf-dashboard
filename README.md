# YVF Adoption Dashboard – CS HAD

Dashboard nội bộ Streamlit gồm 5 trang:
1. Overview
2. Customer Adoption
3. Booking Details
4. User Issues
5. Enhancement Requests

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

File dữ liệu mặc định nằm tại `data/YVF_Adoption_Dashboard_CS_HAD.xlsx`.
