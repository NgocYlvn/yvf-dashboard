YVF ADOPTION DASHBOARD – CS HAD

CÁCH CHẠY NHANH
1. Cài Python 3.11 hoặc 3.12.
2. Mở thư mục project bằng VS Code.
3. Mở Terminal và chạy:
   pip install -r requirements.txt
4. Sau khi cài xong, chạy:
   streamlit run app.py

DỮ LIỆU
- File mặc định: data/YVF_Adoption_Dashboard_CS_HAD.xlsx
- Có thể thay file Excel trực tiếp bằng nút upload ở thanh bên trái.
- Không sử dụng logo công ty để tránh nhầm lẫn với dashboard YVF chính thức.
